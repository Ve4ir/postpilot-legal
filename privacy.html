Privacy Policy

Effective date: September 3, 2026

This Privacy Policy explains how Planer / PostPilot (the “Application”) processes information when the owner connects Facebook Pages and schedules content through the Meta Graph API.

1. Scope

The Application is a private, self-hosted scheduling tool operated for the account owner's own Facebook Pages. This policy applies to information processed through Facebook Login and the Meta Graph API.

2. Information processed

  • Facebook account identifier and display name used to identify the connected account.
  • Facebook Page identifiers, Page names, profile images, and other Page metadata made available through granted permissions.
  • Facebook user and Page access tokens. Tokens are stored in encrypted form.
  • Videos, captions, scheduling times, time zones, and other content deliberately selected by the operator for publication.
  • Technical logs needed to diagnose publishing results, errors, and application security events.

The Application does not request Facebook passwords and does not receive them. Authentication takes place on Facebook.

3. How information is used

  • To connect and display Facebook Pages managed by the operator.
  • To schedule and publish selected content to those Pages.
  • To show publishing status and prevent accidental duplicate posts.
  • To maintain security, troubleshoot errors, and protect the Application from unauthorized access.

4. Storage and sharing

Application data is stored on the local computer or server controlled by the operator. Facebook access tokens and authentication secrets are encrypted at rest. Information is sent to Meta only when needed to authenticate, retrieve Page information, or perform an action requested by the operator.

The Application does not sell personal information, use it for third-party advertising, or disclose it to unrelated parties. Meta processes information under its own terms and privacy policy. GitHub Pages hosts only these public legal pages and does not receive Facebook data from the Application.

5. Retention

Facebook tokens and connected-account identity values are removed when Facebook is disconnected in the Application. Page metadata, schedules, uploaded media, and technical logs remain in operator-controlled storage until the operator deletes them or removes the Application's local data directory. Backup copies, if created by the operator, must also be deleted separately.

6. Security

The Application uses encrypted token storage, owner authentication, two-factor authentication, protected sessions, and request validation. No method of storage or transmission can be guaranteed to be completely secure, so the operator must also protect the host computer, credentials, encryption key, and backups.

7. Your choices and deletion

Facebook permissions can be revoked at any time through Facebook settings. Stored information can be removed by following the Data Deletion Instructions or by contacting the address below. Never send a Facebook password, access token, App Secret, or recovery code by email.

8. Children's privacy

The Application is not intended for children and is not knowingly used to collect information from children.

9. Changes to this policy

This policy may be updated when the Application or legal requirements change. The effective date at the top of this page identifies the current version.
