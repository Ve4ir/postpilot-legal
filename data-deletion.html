Data Deletion Instructions

Last updated: September 3, 2026

Use the steps below to revoke Facebook access and permanently remove information stored by Planer / PostPilot.

Remove the Facebook connection

  1. Open Planer / PostPilot and sign in as the owner.
  2. Open Settings, find the Facebook connection, and select Disconnect Facebook.
  3. Confirm the action. The Application deletes stored Facebook user and Page access tokens, connected-account identity values, OAuth state, and token-expiration information. Connected Pages are disabled.
  4. Open Facebook Settings, go to Business Integrations, select Planer / PostPilot, and choose Remove to revoke the permissions on Facebook.

Delete remaining local data

Disconnecting Facebook does not automatically delete schedules, videos, Page names and identifiers, or technical logs stored locally. To delete everything:

  1. Stop Planer / PostPilot.
  2. Delete the data folder inside the Application directory.
  3. Delete any separate backups that contain the same folder.
This action is permanent.

Deleting the local data folder removes the scheduling database, logs, uploaded media, encrypted tokens, owner login configuration, and publication history from that installation.

Request assistance by email

If you cannot access the Application, send a deletion request to the contact below with the subject Planer Data Deletion Request. Include enough information to identify the connection, such as the Facebook Page name or Page ID. Do not include passwords, access tokens, App Secret values, or recovery codes.

Requests will be acknowledged within seven days and completed within thirty days after ownership can be reasonably verified.
